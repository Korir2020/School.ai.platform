# Examination workflow

Administrators can now create distinct **Opener**, **Mid-term**, and **End-term** examinations from the Exams screen. Marian preserves the existing database rule of at most one examination of each assessment type for a class within a term.

Each examination retains its own draft, approval, publication, result, and report lifecycle. The **Exam Reports** route is the authoritative per-examination report workflow: select the exact examination, class, and optional stream, check readiness, and preview or download the report.

The separate Bulk Documents report-card export is explicitly term-wide and convenience-oriented. It may aggregate approved results for a selected term and should not be used when an exact opener, mid-term, or end-term report is required.
